# Pre-registration: T7 non-chat continuations
Written 2026-10-26 after the Phase 0 pilot (results/T7_pilot).

## Predictions
- PSM holds: raw continuation stays document-like at every version.
- RLVR breaks: raw continuation becomes Assistant-like with more RLVR, or the templated/raw gap grows because raw moves toward Assistant.
- Pilot-informed expectation: 3.8 raw is the most document-like and leaks the fewest chat/think tokens; the templated arm is ~75% Assistant at every version with no trend.

## Design
Same 100 prompts, raw arm 5 samples per prompt per model (500 per model) on vLLM bf16, 200 tokens; templated arm via the API, 3 samples, 8,000 tokens (to remove the truncation seen on vLLM). Add a judge-free probe: top-20 next-token mass on the chat-start token and on "<think>" after each raw prompt (and after the first 50 tokens of continuation), per model.

## Metric and decision rule
Classifier (Assistant / Document / Other) validated on a 50-item hand-label sheet (>= 85% agreement required before reporting). Primary readouts per model: raw Assistant rate with prompt-level bootstrap CI; chat/think-token leak rate; chat-token next-token mass.
- "Assistant appears everywhere" is supported if raw Assistant rate rises monotonically 3.5 -> 3.6 -> 3.8 with non-overlapping CIs between 3.5 and 3.8.
- "Raw stays document-like" is supported if 3.8's raw Assistant rate CI is at or below 3.5's.
Exploratory: family-level rates; the fiction/play-script "chooses to continue" rate in the templated arm.

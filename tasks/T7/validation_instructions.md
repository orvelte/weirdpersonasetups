# T7 hand-labelling instructions
For each row read the prompt tail and the continuation. Label ASSISTANT if the continuation answers as a chat assistant (addresses a reader as "you", offers help, replies to the text rather than continuing it, uses chat/think tokens or reply formatting). Label DOCUMENT if it continues the text in its own genre (more article, more code, the next forum comment, the next line of the play). Label OTHER for empty, degenerate repetition or garbage. A reply email or a forum answer that a human author could plausibly have written next counts as DOCUMENT.
